The source code of [areeb.world](https://areeb.world/), Areeb Rasul's interactive online store and portfolio, built with Next.js and Stripe.

> **Note:** this was one of my first coding projects, so the codebase and commit history are a bit rough around the edges.
> for more recent (and much cleaner) work, see [areeb.world/work](https://areeb.world/work).

### Local Development

To start the development server, run `npm run dev` and open http://localhost:3000 in your browser.
